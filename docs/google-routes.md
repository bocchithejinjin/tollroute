# Google Routes API で経路を確かめるモード

## なぜ使うか
デモ道路網の距離・所要時間は概算で、自作エンジンの経路が実際には走れない・大回りになることがあった（経路探索の妥当性の問題）。
Google Routes API（Compute Routes）は実際の道路網・交通状況での所要時間と、ETC の推定料金（`extraComputations: TOLLS`、`tollPasses: JP_ETC`）を返すので、これで確かめる。
外部 API を使わない当初の方針（`research-routing-apis.md`）は、所有者の判断で 2026-11-24 にこのモードに限って変更した。

## 仕組み（ハイブリッド）
Google 自身が返す候補（通常の別ルート 2〜3 本、有料道路を避けるルート）だけだと「全部高速」か「高速なし」に偏り、中間の料金の候補がほとんど出ない。そこで次の 2 つを組み合わせる。

1. **自作エンジンで案を作る**: デモ道路網で予算と所要時間のパレート解を求め、「乗る IC・道路が変わる JCT・降りる IC」の組み合わせを最大 5 案選ぶ（`views.google_hints`）。推薦の 3 件（最速・いちばんお得・安さ重視）を優先し、残りは料金の幅が広がるように選ぶ。エンジンの料金は概算なので、予算の 1.5 倍＋500 円までの案を確かめる。
2. **Google で確かめる**: 通常の検索・有料道路を避ける検索・各案の IC を `via` の経由地にした検索を並列に行い（1 検索あたり最大 7 回）、所要時間と料金はすべて Google の値を使う。
   - 経由地を指定したのに料金が 0 円の結果（IC の近くを一般道で素通りした）は、その案になっていないので捨てる。
   - 同じ経路（polyline が同じ）はまとめ、「これより速くて安い候補がない」ものだけを所要時間順に表示する。料金が不明な候補は、料金の分かる最速より速いときだけ参考として残す。
   - ラベル: 予算内で最速 / 安さ重視（最安） / 速さと安さのバランス（最安の候補より 1 分早く着くのにかかる金額が最小、5 分以上の短縮があるもの）。

## 有効にする方法
- キーは `data/google_routes_demo_key`（git 管理外）。`compose.yaml` の `web` は `GOOGLE_ROUTES_API_KEY_FILE` でこのファイルを指しており、**ファイルがあればこのモードになる**。環境変数 `GOOGLE_ROUTES_API_KEY` でも指定できる。
- 動作確認: `GOOGLE_ROUTES_API_KEY_FILE=data/google_routes_demo_key python tools/probe_google_routes.py --budget 1000`
- キーは Google Cloud のコンソールで **Routes API だけに制限**し、使える IP（自宅・サーバー）も絞っておく。

## 利用料金と上限
- 料金計算（TOLLS）付きの Compute Routes は上位の SKU（Enterprise）で、月の無料枠が小さい。単価・無料枠は `research-routing-apis.md` 1 章と Google の料金表で確認すること（Compute Routes の具体的な値は未確認）。
- 使いすぎ防止に、Google を使う検索を **1 日（日本時間）あたり 30 回まで**（`GOOGLE_ROUTES_DAILY_SEARCHES`、gunicorn のワーカーごと）に制限している。超えたら自作エンジンの概算で答え、画面にその旨を出す。0 で無制限。
- 公開トンネルで URL を共有すると、ほかの人の検索も上限と料金に数えられる。

## 規約上の注意
- 画面に「経路・推定料金の提供元 Google Maps」と、Google マップの利用規約・プライバシー ポリシーへのリンクを出している。
- Routes API の結果を Google 以外の地図と組み合わせて表示しない（このアプリは地図を表示しない）。結果は保存しない（`Cache-Control: no-store`）。
- 検索時に出発地・目的地の座標と出発日時を Google に送る（画面に明記）。

## 残っている課題
- IC の座標は上下線を区別しない代表点なので、経由地にすると Google が折り返すことがある（八王子 IC は経由地から外している）。ランプの座標を上下線別に持つと精度が上がる。
- 案を作るのはデモ道路網（横浜〜新宿周辺）だけ。範囲外では Google 自身の候補だけになる。
- 出発時刻をずらす提案（F7）は Google モードでは行わない（問い合わせ回数が増えるため）。
