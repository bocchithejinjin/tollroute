# Codex タスク 06: 見た目（配色・デザイン）の作り直し

## 背景
利用者から「今の配色（濃い緑の地に白文字）が見づらい」と指摘があった。利用者が「UI/UX が綺麗で使っていて気持ちいい」と挙げたサイト:
https://yamanotewalk.com/ （web 検索・閲覧してよい）。Claude が見た特徴:

- 鮮やかな 1 色（ターコイズ系）を背景に広く使い、内容は**白いカード**にまとめてくっきり浮かせる。セクションによってクリーム色の地も使う
- カードとボタンに**太い黒の枠線（2〜3px）**と、**ぼかさない、右下にずらした黒い影**（いわゆるネオブルータリズム）。角は大きめの丸み。押せる場所がひと目で分かる
- **大事な数字を大きく太い書体**で見せる（「4,937 人」）。単位は小さく
- 丸みのある、やわらかい日本語の見出し書体。点線の区切り、番号付きの丸いバッジ
- アクセント色は最小限（時刻だけ赤など）。矢印付きの丸いボタン
- スマホ幅の 1 カラムが基本

## やること
1. 上の**作り方（スタイルの考え方）を取り入れる**。ただし yamanotewalk のロゴ・名前・配色の組み合わせ・文言を**そのまま真似しない**。このアプリ独自の配色にする（例: 高速道路の案内標識の緑、ETC の紫、アスファルトのグレーなどから発想）。
2. **配色を 3 案**作り、画面上部の小さな切り替え（または `?theme=` パラメータ）で見比べられるようにする（CSS 変数で切り替え。選んだ案は localStorage に保存、try/catch で囲む）。既定は、あなたがいちばん良いと思う案。
3. 見せ方:
   - 「予算内で最速」などの選んだルートは、白いカード＋太い黒枠＋ずらした影。所要時間と高速代を大きく太く（単位は小さく）
   - ほかの候補のカードも同じ様式で小さく。選択中は影を消して少し押し込んだ見た目にするなど、状態が分かるように
   - 予算の目安ボタン・ナビのボタンは、押せることが明らかな形（44px 以上）
   - 道順は、番号付きの丸いバッジと点線の区切りで、ステップ（一般道 → 高速 → 一般道）が追える形に
   - 文字と背景のコントラストは WCAG AA（本文 4.5:1、大きな文字 3:1）以上を確保する。3 案とも
4. 書体: Google Fonts を 1〜2 種類まで使ってよい（例: 見出しは丸ゴシック系、数字は太いもの。`display=swap`、読み込めなくても崩れないこと）。
5. 変更するのは `routes/static/routes/search.css`、`routes/templates/routes/index.html`、`routes/static/routes/search.js`（テーマ切り替え分）だけ。API・`routes/views.py`・`engine/` は変更しない。機能（候補・お得度・ナビ連携・近似の警告・概算の注記・出典表示）は削らない。

## 確認
- `docker compose -f .devcontainer/compose.yaml exec -T app pytest -q routes` が通ること（Docker に繋がらなければ報告）。
- 可能なら画面を描画して確認する。できなければ、その旨を報告する。
- `docs/ux-redesign.md` の末尾に「見た目の改訂（配色 3 案）」として、各案の色（16 進）、コントラスト比、狙いを表で追記する。
