# 高速代の予算内最速ルートの UI 見直し

## 想定する使い方

利用者は、首都圏を車で移動するアプリの持ち主。出発前に自宅でスマートフォンを開き、「高速代は 1,000 円くらいまで。何分早く着くなら払う価値があるか」を短時間で決めたい。よく使う地点は同じで、金額の上限はその日の急ぎ具合で変わる。行き方が決まったら、使い慣れたナビに渡す。

毎回の入力が少なく、予算内での到着時刻がすぐ分かることが、繰り返し使う理由になる。急いでいない日は「いくら節約できて、何分余計にかかるか」で判断できる。

## 旧画面の問題点

- スマートフォンではフォームと「お得度」の説明が結果より先に並び、検索済みでも答えを見るにはスクロールが必要だった。
- 候補ごとに道順・料金内訳・ナビボタンが並び、支払う金額と到着時刻の差を拾いにくかった。
- 駅欄と自由入力欄が常に並び、実際に使われる地点が分かりづらかった。定番ルートでも入力し直す必要があり、上限スライダーからどの金額を選ぶかも判断しづらかった。
- 予算 0 円では一般道の所要時間は分かるものの、同じ画面からそのルートをナビに渡せなかった。全候補は表の行やグラフの点を押す仕組みで、タッチやキーボードで操作しづらかった。

## 採用した改善

1. **結果を上に置く。** 前回の条件（初回は横浜駅から新宿駅、上限 1,000 円）を「今すぐ」で検索する。上部に地点・時刻・予算を残し、その直下で所要時間、到着予定、高速代、一般道からの短縮を読める。予算内で一般道が最速なら、同じ位置に 0 円の結果を出す。
2. **差を見て候補を選ぶ。** 最速を初期選択にし、API の候補と一般道を同じ並びのボタンで示す。最速からの料金差と時間差を表示する。選んだ候補の IC・道路名・ナビを表示し、道順と割引明細はその場で開ける。
3. **よく使う条件をすぐ入力できる。** 0・500・1,000・1,500 円の目安から選べて、任意の整数も入力できる。駅と住所・座標は選択式にし、日時指定欄は使うときだけ表示する。「今すぐ」は検索時の日本時間を使う。利用者が検索して成功した地点と予算はこのブラウザに保存し、条件欄で消せる。
4. **予算や時刻を変える理由を示す。** 時刻変更の提案では出発時刻、所要時間、料金差を提示する。全候補の横棒で時間を比べ、金額ボタンで同じ地点・出発日時をその予算で検索できる。テキストでも料金と時間を読めるようにする。
5. **概算の範囲を先に伝える。** ヘッダーに「料金・時間は概算」を常時表示する。近似になった場合は候補の直前で注意を出す。見積もりの前提とナビへの引き渡し方は詳細に置く。外部への地点の引き渡しは利用者がナビボタンを押したときに行う。

## 見送った案

- **地図の埋め込み。** アプリ内での判断は料金・時間・IC 名で行い、地図と案内はナビ側で見る。スマートフォンの最初の画面を結果に使える。
- **最安・最速などの専用タブや並べ替え。** 少数の候補を一度に見比べられる。最速とお得が同じルートになる場合も、同じ候補の重複表示を避けられる。
- **地点ごとのお気に入り一覧や複数の履歴。** 定番の組み合わせを再利用する用途には、最後に検索できた地点と予算の復元で足りると判断した。
- **管理画面向け UI と外部ライブラリ。** 検索結果が中心の一画面には、標準のフォーム、折りたたみ、CSS の棒グラフで必要な操作を実装できる。

## 見た目の改訂（配色 3 案）

「濃い緑の地に白文字が見づらい」という指摘を受けて作り直した。利用者が気持ちよいと挙げたサイトから**作り方だけ**を取り入れ、ロゴ・名前・配色・文言は使っていない。

- 鮮やかな 1 色を画面の地に広く使い、内容は**白いカード**に載せる。カードとボタンは**太い黒枠（3px）とぼかさない右下の影**。押せる場所がひと目で分かる。
- 選んだルートのカードでは、**所要時間と高速代を大きく太い数字**で見せ、単位（時間・分・円）は小さくする。
- ほかの候補も同じ様式の小さめのカード。選択中は影を消して右下に押し込み、チェック印と淡いアクセント色の地で示す。
- 予算の目安・ナビ・配色の切り替えは丸いボタン（高さ 44px 以上、ナビと検索は 52〜56px）。選んだ予算はアクセント色で塗る。
- 道順は、選んだカードに「① 一般道 → ② 高速 → ③ 一般道」の流れ（番号付きの丸いバッジと点線）を常に出し、詳細を開くと区間ごとに同じバッジと点線の区切りで並ぶ。高速区間のバッジは淡いアクセント色。
- 書体は Google Fonts の 2 種類まで: 見出し・本文に丸ゴシックの Zen Maru Gothic、数字に Outfit（`display=swap`）。読み込めない場合はヒラギノ丸ゴ・BIZ UDPゴシック・Yu Gothic UI・メイリオ、数字は Arial 系に代わり、レイアウトは崩れない（フォントを外した状態で確認済み）。
- 配色は画面上部の「配色 緑／紫／灰」で切り替える。`?theme=guide|etc|asphalt` でも指定できる。選んだ案は localStorage に保存（try/catch で囲み、保存できない環境でも既定の配色で動く）。描画前に `<head>` の小さなスクリプトで適用し、既定の色が一瞬見えないようにした。
- 文字を直接載せるのは白・クリーム（wash）・淡いアクセント・画面地だけ。画面地の上の文字は黒（ink）に限り、灰色の補足文字は置かない。概算とナビの注記も白いカードに入れた。
